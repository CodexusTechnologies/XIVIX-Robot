## About XIVIX Robot

**XIVIX Robot** is a scalable humanoid robotics platform designed to bring advanced robotics, intelligent electronics, and connected technologies together in one integrated system.

The vision behind XIVIX is simple:

> **One engineering design. Multiple sizes. Endless possibilities.**

Instead of designing an entirely new robot for every application, XIVIX aims to establish a common engineering platform that can be adapted into different sizes and configurations.

From an affordable educational robot to a larger humanoid platform, XIVIX explores how mechanical engineering, electronics, embedded systems, artificial intelligence, and Internet of Things (IoT) technologies can work together.

Designed with the vision of being **Made in Sri Lanka**, XIVIX aims to contribute to local robotics innovation and create opportunities for research, development, and education.
